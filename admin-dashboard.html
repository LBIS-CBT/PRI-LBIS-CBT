Password Access & Recovery

Understand what administrators can safely view or recover.

Existing passwords cannot be viewed.

Supabase Authentication stores password hashes, not readable passwords. For security, LBIS CBT must never expose a teacher's or administrator's existing password. The correct action is to reset the password and issue a new temporary credential securely.

This section will provide audited reset actions for administrator and teacher accounts. Examination password recovery will be available only after examination-password support is implemented.
